# MCM — Vila Aurora | Protótipo 0.1

Protótipo estático para GitHub Pages.

## Teste local
Abra `index.html` em um navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta mantendo `css/` e `js/`.
3. Em Settings > Pages, escolha publicação a partir da branch principal (`main`) e pasta `/root`.
4. Aguarde a URL do GitHub Pages ser disponibilizada.

## Observação
Esta versão NÃO envia dados a servidor. Para facilitar o desenvolvimento, os eventos de resposta são registrados apenas no console do navegador.
